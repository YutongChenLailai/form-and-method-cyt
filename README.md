# Form and Method CYT

An interactive bilingual research map for the Binhe Xincun, Shenzhen research project.

The project explores how an AI-mediated feedback process can translate residents’ situated knowledge into traceable, constraint-aware architectural design revisions, with resident review and on-site validation.

Open the live map: https://yutongchenlailai.github.io/form-and-method-cyt/
