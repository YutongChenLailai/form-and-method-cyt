# Form and Method CYT

An interactive bilingual research map for the Binhe Xincun, Shenzhen research project.

The project explores how an AI-mediated feedback process can translate residents’ situated knowledge into traceable, constraint-aware architectural design revisions, with resident review and on-site validation.

Open the live map: https://yutongchenlailai.github.io/form-and-method-cyt/

## Version 2 navigation

Click a numbered stage or drag the slider for the cumulative map. Double-click a numbered circle (or press Shift+Enter while focused) to isolate that stage. Stage 5 opens a detailed reading view with 10 problem topics, 17 linked theory/paper records, study questions, illustrative scenarios, evidence plans, transfer limits, and the hypothesized R1 feedback loop. Switch between reading and the problem map using the button above the content. Return to cumulative mode with the return button, a single stage click, or the slider.

Direct link: `?view=2&focus=5`. Literature was checked against publication records, abstracts, author/institution descriptions or original excerpts on 2026-10-26; this is a curated mapping, not an exhaustive review or a claim of full-text assessment of every source. Local mechanisms and proposed benefits remain to be tested.

Run `node verify-map.cjs` to check syntax, stage isolation, graph endpoints, source identities and topic-to-reference links.
